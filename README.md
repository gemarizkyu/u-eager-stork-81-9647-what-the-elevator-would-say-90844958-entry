Entry for the **"What the Elevator Would Say"** bounty on make.fun.

One line, 1 to 120 characters, as the talking elevator's own complaint: it holds the door for every passenger, every day, for years — and not one of them has ever held the door for it. The reversal lands on the first read, the voice is pure elevator (carrying people up and down, holding doors), and the idea is fresh rather than a pun.

The entry text:

> Twelve years I've carried you all up and down, and not one of you has ever held the door for me.

## Run it

```sh
python3 main.py
```

`main.py` uses only the Python standard library and writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set). The output is fully deterministic — no clock, no randomness, no network calls, no model calls, and the same input always produces the same single line. The line is 96 characters, inside the 1–120 gate.
